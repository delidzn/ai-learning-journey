## 📘 یادداشت‌ها

### روز ۱: LLM
- مدل زبانی در اصل **تکه بعدی متن** را حدس می‌زند.
- متن به **توکن** شکسته می‌شود و هزینه بر اساس توکن حساب می‌شود.
- مدل فقط چیزی را می‌داند که در **context** به آن داده شده است.
- مدل ممکن است اشتباه کند، پس همیشه کد را بررسی کنید.

### روز ۲: API
- API راهی است که **دو برنامه با هم حرف بزنند**.
- هر درخواست شامل: آدرس، متد، هدر و بدنه است.
- `GET` = خواندن، `POST` = ساختن، `PUT` = تغییر، `DELETE` = پاک کردن
- کدهای وضعیت: `2xx` موفق، `4xx` خطای من، `5xx` خطای سرور
- **کلید API را هرگز روی GitHub نمی‌گذارم!** 🔑

### روز ۲: GitHub
- **Git** تاریخچه تغییرات را نگه می‌دارد و **GitHub** آن را آنلاین می‌کند.
- `commit` = ذخیره، `push` = فرستادن، `pull` = گرفتن
- `.gitignore` فایل‌های خصوصی را از آپلود شدن دور نگه می‌دارد.
